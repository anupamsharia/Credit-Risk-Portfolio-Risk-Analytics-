# Executive Dashboard

Part of the **Credit Risk & Portfolio Risk Analytics** portfolio by **Anupam Sharia**.

---

## 📌 Overview
`executive_dashboard.html` is a standalone, interactive single-page dashboard built with Vanilla HTML, modern CSS, and Chart.js.

### Tabs & Interactive Visualizations:
1. **Credit Risk Model:** Dynamic ROC curves comparing Gradient Boosting, Random Forest, and Logistic Regression, alongside profit-maximizing threshold metrics.
2. **Portfolio Risk:** Efficient Frontier visualization, Monte Carlo simulations, Drawdown trajectories, and Correlation Stress Testing.
3. **Finance Operations:** Actual vs. Budget variance bar charts and monthly revenue/expense trendlines.

---

## 🚀 How to Run
Double-click `executive_dashboard.html` to open it in any web browser (Chrome, Edge, Safari, Firefox). No local server or dependencies are needed!
